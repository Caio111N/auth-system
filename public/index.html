ARCHITECTURE / 06 LAYERS

Como funciona a
proteção por baixo.

Decisões técnicas pequenas que formam uma experiência de autenticação confiável.

01 / HASH

Senhas protegidas

bcrypt transforma cada senha em um hash irreversível antes de chegar ao banco.

bcrypt · cost 12
02 / SESSION

JWT curto

Tokens de acesso com expiração de 15 minutos, issuer e audience validados.

HS256 · exp 15m
03 / DEFENSE

Rate limiting

Tentativas de login e recuperação são limitadas para reduzir ataques automatizados.

429 · retry-after
04 / PRIVACY

Anti-enumeração

Respostas neutras evitam revelar se um e-mail existe na base de usuários.

generic response
05 / RECOVERY

Reset opaco

Tokens aleatórios são armazenados somente como hash e expiram após o uso.

sha-256 · one-time
06 / QUALITY

Testes automatizados

O middleware e o model têm testes básicos para manter o contrato de segurança.

node:test · 3 passing

ABOUT / THE PROJECT

Segurança não precisa
ser uma caixa preta.

Este projeto é uma demonstração visual e funcional de um sistema de autenticação Node.js + Express + MongoDB. O frontend expõe as decisões de engenharia sem sacrificar clareza: cada tela é uma extensão do contrato seguro da API.
