# Segurança

Obrigado por ajudar a manter o Auth System seguro. Não publique credenciais, tokens ou detalhes exploráveis de uma vulnerabilidade em issues públicas.

Envie um relato privado ao mantenedor do repositório ou use o recurso de relato privado de vulnerabilidades do GitHub, se estiver habilitado. Inclua passos para reproduzir, impacto e uma correção sugerida quando possível; remova segredos reais de logs e exemplos.

Este projeto é demonstrativo. Não o exponha em produção sem configurar TLS, domínio, SMTP, CORS e proxies confiáveis, além de revisar seus controles operacionais.
